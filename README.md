# The Mentalist

## About the Series

**The Mentalist** is my favorite TV series. It is a crime drama about Patrick Jane, a former psychic who helps solve crimes using observation and deduction.

### Main Characters

- Patrick Jane
- Teresa Lisbon
- Kimball Cho
- Wayne Rigsby
- Grace Van Pelt

### Why I Like It

1. Interesting mysteries
2. Smart investigations
3. Great characters
4. Exciting storylines

> "The truth is often hiding in plain sight."

`Patrick Jane uses observation and psychology to solve cases.`
